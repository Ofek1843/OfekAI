# Third-party licence review

Direct production dependencies declared in `package.json`: Express (MIT), Firebase Admin (Apache-2.0), ImageKit SDK (MIT), dotenv (BSD-2-Clause), http-proxy-middleware (MIT), and autocannon (MIT). This inventory is not a complete transitive-dependency licence opinion.

ExerciseDB/AscendAPI media, Spoonacular imagery, and Hugging Face image generation are disabled unless their explicit `THIRD_PARTY_*_ENABLED` environment flag is set after licence/terms review. Their attribution or prototype availability is not treated as production permission.

Before enabling an external service, record: agreement URL/version, permitted data categories, permitted territory, attribution requirements, commercial-use status, deletion/retention terms, contact owner, and approval date.
