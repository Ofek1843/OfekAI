# Owner provider-agreement checklist

For every enabled provider, the owner must retain the current agreement/DPA, configured account owner, region/transfer information, security contact, deletion request path, and renewal/review date. This repository intentionally stores only environment-variable names and never provider secrets.

Providers currently referenced by code: Firebase/Google, OpenAI, ImageKit, Render, PayPlus, Telegram, ExerciseDB/AscendAPI, Spoonacular, Frankfurter, and optional Hugging Face. “Referenced” does not mean “approved for production use.”
